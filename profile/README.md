# Quip Network

Quip Network gives you quantum compute without owning a quantum computer, and post-quantum security for digital assets on the chains you already use.

## Get started

- **[developers.quip.network](https://developers.quip.network/)** is the starting point for building on Quip Network. It has quickstart commands for the SDKs and the compute toolchain, testnet connection details, docs for coding agents, and a list of every repository.
- **[aglais.quip.network](https://aglais.quip.network/)** is Aglais, the public test network. Its token, AGLS, has no value. You cannot buy, sell, or redeem it, and balances can be reset at any time.

## Find your way around

| If you want to | Start with |
|---|---|
| Write and run optimization problems on quantum or classical solvers | [xquad](https://github.com/QuipNetwork/xquad), [xq-py](https://github.com/QuipNetwork/xq-py) |
| Sign with post-quantum, hash-based signatures | [hashsigs-rs](https://github.com/QuipNetwork/hashsigs-rs), [hashsigs-ts](https://github.com/QuipNetwork/hashsigs-ts), [hashsigs-py](https://github.com/QuipNetwork/hashsigs-py), [hashsigs-solidity](https://github.com/QuipNetwork/hashsigs-solidity), [pqhybridsign](https://github.com/QuipNetwork/pqhybridsign) |
| Build on Ethereum with Quip contracts | [ethereum-sdk](https://github.com/QuipNetwork/ethereum-sdk), [quip-swap-solidity](https://github.com/QuipNetwork/quip-swap-solidity) |
| Run a node | [quip-node-manager](https://github.com/QuipNetwork/quip-node-manager), [quip-validator](https://github.com/QuipNetwork/quip-validator) |
| Run a miner on your own hardware | [quip-solver](https://github.com/QuipNetwork/quip-solver), and the CPU, CUDA, Metal, and D-Wave solvers it links |

## Contribute and report problems

Development happens on GitLab, at [gitlab.com/quip.network](https://gitlab.com/quip.network). The GitHub repositories are copies of the GitLab projects.

Open an issue in the repository that has the problem. Report a security vulnerability privately, as the [security policy](https://github.com/QuipNetwork/.github/blob/main/SECURITY.md) describes. Do not open a public issue for a vulnerability.
